Ensure your system meets the following requirements:

## ⚙️ Setting Up

Once you have downloaded the file, follow these steps to set up matryoshka:

### For Windows Users:

1. Locate the downloaded file in your Downloads folder.
2. Double-click the file to run it.
3. Follow the on-screen instructions to complete the installation.
4. Once installed, you can find the application in your Start Menu.

### For macOS Users:

1. Open Finder and go to your Downloads.
2. Double-click the downloaded file.
3. Drag the matryoshka icon to your Applications folder.
4. Open your Applications and find matryoshka to start using it.

### For Linux Users:

1. Open your terminal.
2. Navigate to your Downloads directory using:
   ```bash
   cd ~/Downloads
   ```
3. Make the file executable by running:
   ```bash
   chmod +x matryoshka*
   ```
4. Run the file using:
   ```bash
   ./matryoshka*
   ```
